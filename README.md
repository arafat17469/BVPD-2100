# BVPD-2100
A Bangla vishing dataset based on victim-reported fraud scenarios with labeled texts and 200 simulated call recordings with human transcripts.

## Dataset creators

- Arafat Rahman
- [Nahid Hasan](https://pundrauniversity.ac.bd/profile/computer-science-and-engineering/nahid-hasan)
